# Design Context — meetguns portfolio

> Brand voice, audience, and tone rules. Read before any visual change. Mechanical token reference lives in [AGENTS.md](AGENTS.md) and [styles/tokens.css](styles/tokens.css); this file is _why_, not _what_.

## Target audience

- **Primary**: hiring managers and design/eng leads evaluating Ganapati for senior product/UX work.
- **Secondary**: peers in the design + frontend community discovering the site through writing, talks, or shared work.
- **Tertiary**: future collaborators and clients sizing up taste before reaching out.

These readers skim. They came for proof — projects, writing, range. They stay if the site has a point of view.

## Use cases

- Read the home page in 30 seconds and form an instinct ("good taste / not")
- Browse `/work` to assess depth, breadth, and recency
- Read a `/blog` post end-to-end (long-form, code, images)
- Skim `/about` for tone and trajectory
- Bookmark, return, share a specific post
- Cycle through accent / theme / mono / plain to "play" the picker as a tiny instrument (the chime is intentional)

## Brand personality / tone

Three words: **warm, intentional, hand-built.**

- **Warm, not corporate.** Earthy palette named after South Indian craft materials — khadi, turmeric, brass, jaggery, tamarind, kohl. Soft warm shadows (rgba on `60,40,25` in light, deeper on `0,0,0` only in dark). Friendly radii — no sharp corners; smallest control is `--r-xs: 6px`, largest container is `--r-2xl: 36px`, `--r-pill: 999px`. Subtle grain overlay (`.grain` + `--grain-opacity`). Light mode is "unbleached handloom cotton" (`--khadi: #fbf6ea`); dark mode is "warm candlelit black" (`#1a1411`, never pure `#000`).
- **Intentional, not maximalist.** A type system with one display sans (Geist), one editorial italic serif (Fraunces), one mono (JetBrains Mono). 12-step fluid scale, 7 weight roles, 5 line-height roles. Discipline rule from the design bundle: **"one flourish per page, max."** The playfulness comes from restraint + a single moment of character, not from spraying decoration everywhere.
- **Hand-built, not machine-stamped.** Field-notes voice in `tokens.css` comments ("monsoon clay", "grandmother's eyeliner", "filter coffee decoction"). Variable-axis Fraunces tuned for soft + wonky character (`SOFT 100, WONK 1, opsz 144`) on flourish moments — hover nudges `slnt -4` for a wink. Italic Fraunces drop caps on article first paragraphs, colored with the active accent (or `--highlight` in dark). Numbers set in tabular or oldstyle figures, not browser default.

The reader should feel: _someone made this, with care, and they have a point of view._

## Surfaces that express the brand

These are the visible affordances. When you make a design move, ask: am I supporting these or fighting them?

- **8-accent picker** (`lib/accents.ts`). 6 hue accents named for craft materials (terracotta = monsoon clay, saffron = turmeric milk, sage = neem leaf, rose = gulkand rose, plum = jamun, coffee = filter coffee) plus 2 polarity overrides — `paper` (white-bg, black-ink) and `ink` (black-bg, white-text). Each accent has a freq tuned to a C-major pentatonic spread, so cycling the picker plays a distinct chime; switching mode rings the appropriate "polarity bell" (`paper` E6 bright, `ink` C3 deep gong). The palette is the brand voice in interaction form.
- **Three modes** (`AccentProvider` exposes `mode = colorful | mono | plain`). `colorful` is the default — accent + soft tint everywhere. `mono` flattens chroma (`data-mono="true"`). `plain` collapses to two-tone via the pure accents (`paper` in light, `ink` in dark). Each mode is its own aesthetic statement; the `0` shortcut cycles them.
- **View-transition iris reveal**. Every theme/accent/mode change radiates a circular wipe from the click origin (or crossfades on keyboard). Animated via `@property`-typed `--vt-r-now`, fallback WAAPI on browsers without `@property`. 600ms, `cubic-bezier(0.33, 1, 0.68, 1)`. The "wow" lives here — pick a chip, watch the page repaint outward from your fingertip.
- **No-flash script** (`app/layout.tsx`). Theme/accent/mono are persisted (`mg_theme`, `mg_accent`, `mg_mono`) and re-applied before paint. The site never blinks.
- **Shift-hold keyboard hints** (`HintLayer`). Hold `Shift` for 120ms and floating key glyphs appear next to every shortcut-bound element. The `?` key opens a help dialog. Power-user readable, never in the way otherwise.
- **WebAudio FX** (`FXProvider`). Nav/back/primary/toggle each have a tuned timbre (880Hz triangle, 380Hz sine, 620Hz sine, 540Hz triangle). The whole site clicks like one instrument. Auto-mutes under `prefers-reduced-motion` unless the user explicitly toggled sound on.
- **ShaderHero**. Domain-warped FBM + caustic shimmer behind the home hero, mouse-reactive, accent-tinted. Pauses when offscreen. DPR-clamped for perf. Reduced-motion gated.
- **Drop caps + flourish**. Article first paragraphs drop a Fraunces italic capital in the active accent. The `.flourish` class (italic Fraunces, max axes) is reserved for the page's defining moment — _one per page_.

## What to avoid

- **Generic SaaS aesthetics.** Cool greys, drop-shadow cards, neutral interface fonts everywhere, hairline 1px borders on white. None of that.
- **Decorative font swaps for their own sake.** No Inter→Lora→Fraunces→…; commit to Geist + Fraunces + JetBrains Mono.
- **Loud animations.** Motion is `--ease-out` (utility) or `--ease-spring` (character). No bounce-juice, no overshoots beyond the spring, no "gotcha" entrance choreography.
- **Flat black `#000` or pure white `#fff`.** Reserved for the `paper` and `ink` accents _only_. Body text and chrome use warm tints — `--moonless: #0F0B09`, `--khadi: #FBF6EA`.
- **Multiple flourishes per page.** Breaks the "one flourish max" rule and dilutes the moment.
- **Hardcoded hex / px / cubic-bezier in component code.** All visual values resolve through tokens. Bypassing the system erodes it.
- **Loud accent application.** `--accent-soft` is the right value for fills 90% of the time. Solid `--accent` is for emphasis, focus rings, and the iris reveal — not field labels.

## Design system anchors

- **Tokens**: [styles/tokens.css](styles/tokens.css) + the recolor / view-transition vars in [app/globals.css](app/globals.css). Color, type, weights, spacing, radii, shadows, motion. Every value here has a name; new code references the token, not the value.
- **Accents**: [lib/accents.ts](lib/accents.ts) — 8 definitions with id/label/hex/soft/freq/polarity. Single source of truth for colors AND their pitch.
- **Type**: 3 families, 12-step fluid scale (`--t-micro` → `--t-display`), 7 weight roles (`--fw-light` → `--fw-bold`, plus `--fw-display: 350` for Fraunces and `--fw-readable: 450` for Geist body).
- **Flourish**: `.flourish` class — italic Fraunces, max-character variable axes, hover micro-animation. Reserve for the page's defining personal moment (the hero word). Section-head italics use the quieter `.section-accent` sibling (lower SOFT/WONK, no wink) so the one `.flourish` per page stays the loud moment.
- **Drop cap**: first paragraph of every article gets a Fraunces italic dropped initial (`.dropcap::first-letter` in `styles/tokens.css`).
